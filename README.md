## Selected Project Highlights

### Corporate Delisting Risk Prediction
- Built a financial-risk prediction pipeline using **2021–2023 financial ratios** to predict **2024 delisting outcomes**.
- Used firm-size-based median imputation and missing indicators to preserve information in sparse financial disclosures.
- Improved the **F2-score from 0.5263 to 0.7246** by optimizing the decision threshold while maintaining recall.

### KNHANES RAG Assistant
- Developed a RAG system for navigating **KNHANES multi-wave user guidelines**.
- Combined **Dynamic Scope**, **Batch-by-Batch Retrieval**, and **Hybrid Search** to reduce cross-wave information confusion.
- Implemented a real-time retrieval and response pipeline with **FastAPI** and **WebSocket**.

### Gyeonggi Pass DID Analysis
- Reconstructed card-spending data into a **23-month city-month-age-group balanced panel**.
- Applied **Difference-in-Differences** with unit and month fixed effects.
- Conducted sector-level, CPI-adjusted, and implementation-month-excluded robustness analyses.
